# iOS 键盘输入适配设计

## 目标

确保 App 内所有会唤起系统键盘的输入控件在键盘出现后保持可见、可操作，并统一提供自然的键盘收起体验。适配范围包括日记、日记总结、写信正文、登录、情绪自定义输入、写信化名和引导流程。

## 现状与根因

项目共有 7 类 SwiftUI 键盘输入场景。当前实现混用了三种策略：

1. 依赖 SwiftUI 默认键盘安全区避让；
2. 使用滚动容器自动将聚焦控件滚入可见区域；
3. 通过 `.ignoresSafeArea()` 或 `.ignoresSafeArea(.keyboard)` 忽略键盘安全区。

日记页已使用 `.ignoresSafeArea(.container)` 保留键盘安全区，并在聚焦后滚动到最新内容。主要缺陷来自前景内容忽略键盘安全区，以及部分页面缺少滚动容器、焦点状态或键盘收起入口。现有 `KeyboardAwareModifier` 通过通知手动计算键盘高度，但未被使用；这类计算容易与 SwiftUI 自带避让叠加，也较难正确覆盖悬浮键盘、第三方键盘和横屏，因此不作为本次方案基础。

## 设计方案

采用“系统原生避让 + 页面级容器适配”：

- 背景可继续铺满屏幕，但承载输入控件和操作按钮的前景容器不得忽略键盘安全区。
- 滚动页面统一使用 `.scrollDismissesKeyboard(.interactively)`，允许用户下拉收起键盘。
- 需要程序化控制的页面使用 `@FocusState`；点击空白、完成操作或切换非文本交互时清除焦点。
- `phonePad`、`numberPad` 等没有 Return 键的输入类型提供键盘工具栏“完成”按钮。
- 日记聊天和长内容页面在聚焦后保持当前输入区域及最新内容可见，不手动叠加固定键盘高度。
- 不在 App 根视图统一上移所有页面，避免非输入区域整体跳动和双重避让。

## 页面改动

### 日记页

保留现有 `.ignoresSafeArea(.container)`、交互式键盘收起和聚焦后滚动到底部的实现。补充回归验证，确保输入条始终位于键盘上方，最新消息不被遮挡。

### 日记总结页

将全局安全区忽略限制在背景层，恢复前景 `VStack` 的键盘安全区响应。保留滚动收起和键盘工具栏，并保证长文本编辑区及底部完成按钮可达。

### 写信正文页

保留系统默认避让。补充交互式收起或明确的完成入口，验证 `TextEditor` 与底部工具栏在键盘出现后均保持可见。

### 登录页

将内容放入可滚动或可压缩的键盘安全容器，为手机号和验证码建立焦点顺序。数字键盘提供“完成”按钮；滚动或点击空白可收起键盘。

### 情绪自定义输入

由承载弹层的滚动容器负责键盘避让和交互式收起。聚焦自定义输入时保证输入框可见；选择情绪、确认或跳过时清除焦点。

### 写信化名页

为化名输入增加焦点管理。滚动、选择下方选项或完成操作时可收起键盘，且输入框继续由 `ScrollView` 自动滚入可见区域。

### 引导输入页

移除前景内容上的 `.ignoresSafeArea(.keyboard)`。背景保持全屏，输入区和确认按钮参与键盘安全区布局。对普通文字输入和姓名输入分别保证聚焦控件与主要操作按钮可见。

## 状态与数据流

键盘展示状态不新增全局共享对象。每个页面只维护自身焦点枚举或布尔状态，焦点改变由用户点击、提交、滚动和页面生命周期驱动。业务输入值继续使用现有 `@State` 或绑定，不改变持久化和业务提交流程。

## 异常与边界情况

- 横屏、小尺寸设备、动态字体和第三方键盘下，不依赖固定键盘高度。
- 当页面内容超过键盘后的可用高度时，以滚动保证输入和主要操作可达。
- 自动聚焦页面在首次出现时仍可唤起键盘，但不得遮挡输入或确认按钮。
- 语音输入与键盘共享文本状态，不改变语音服务生命周期。
- 页面退出、确认或切换到日期选择等非文本交互时清除焦点，避免键盘残留。

## 测试策略

先添加会失败的静态回归检查，覆盖：

- 所有 `TextField`、`TextEditor` 输入点均登记在键盘适配清单中；
- 输入前景容器不存在危险的 `.ignoresSafeArea(.keyboard)`；
- 滚动输入页面具有交互式键盘收起策略；
- 数字键盘页面具有显式收起入口。

实现后运行静态检查和 iOS 工程构建，并在模拟器逐页验证：

1. 聚焦输入框后输入控件位于键盘上方；
2. 当前内容和主要操作按钮可见或可滚动到达；
3. 下拉、点击空白或“完成”可以收起键盘；
4. 提交、切换控件和返回页面不会遗留错误焦点；
5. 小屏设备和横屏不发生双重上移或布局跳变。

## 非目标

- 不重构现有业务状态管理或导航结构；
- 不引入第三方键盘观察库；
- 不使用固定高度模拟键盘；
- 不修改与输入适配无关的视觉样式和业务逻辑。
